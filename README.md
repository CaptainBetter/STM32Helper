# STM32 极速翻译助手 (STM32 Quick Decode)

> **V2.0** · 复制 STM32 代码，按 `Alt+Q`，不离开 Keil 就能看懂。

一款面向 STM32 初学者的 Windows 桌面小工具：选中 Keil 里的函数、宏或注释（标准库、HAL 库都适用），`Ctrl+C` 后按 `Alt+Q`，即可在置顶悬浮窗中看到由 DeepSeek 生成的结构化中文解释。

## 💡 项目初衷 (Why I built this)

对于国内的 STM32 初学者来说，庞大的底层库和全英文的官方文档极其不友好。那些冗长的函数名（如 `TIM_ETRClockMode2Config`）和晦涩的宏定义，每次查阅都需要切出 Keil 去浏览器搜索，极其打断写代码的心流。

为了解决这个痛点，我借助 DeepSeek Harness 编写了这款轻量级的本地桌面辅助工具。让你无需离开 Keil 界面，即可实现代码的无感翻译与解析。
极简使用说明：1.以管理员身份运行run.bat
2.在keil里面 "ctrl+c"选中想翻译的项，Alt+Q 得大结果
3.Alt+C关闭隐藏窗口 如果不想用了Alt+G退出程序
## ✨ 核心功能 (Features)

- **极速唤醒**：在 Keil 中选中代码或注释，`Ctrl+C` 复制后按下 `Alt+Q`，即可在悬浮窗中查看 150 字以内的结构化解释（作用、英文拆解、参数解析、调用示例）。
- **深度解析**：结合大模型，不仅提供中文翻译，还会自动拆解英文缩写，并给出在 STM32 中的具体使用场景和 C 语言调用示例。
- **零侵入**：不需要安装 Keil 插件，也不修改工程配置；任何能复制文本的编辑器都能配合使用。
- **无感运行**：置顶、无边框、黑底绿字的悬浮窗，看完即走；配合 `run.bat` 由 `pythonw.exe` 静默启动，不保留控制台窗口。
- **随手收起**：`Alt+C` 隐藏窗口，进程继续在后台待命；再按 `Alt+Q` 随时唤出。
- **稳定省心**：0.7 秒防抖，连续触发只处理一次；新请求会自动作废旧结果，避免窗口被过期回答“顶掉”。Key 无效、网络超时、额度不足等情况都会直接在窗口里给出中文提示。
- **离线预览**：`--demo` 模式不调用 API，也能查看悬浮窗样式。

## ⌨️ V2.0 快捷键说明 (Hotkeys)

| 快捷键 | 作用 |
| --- | --- |
| `Alt+Q` | 读取剪贴板并弹出翻译窗口；窗口已打开时再按一次会重新读取并刷新 |
| `Alt+C` | 隐藏翻译窗口（小退）；进程继续在后台待命，再次按 `Alt+Q` 可重新唤出 |
| `Alt+G` | 彻底退出翻译助手进程（大退） |
| `Esc` / 鼠标左键 | 关闭当前悬浮窗，效果同 `Alt+C` |

> ⚠️ **注意顺序：先 `Ctrl+C`，再 `Alt+Q`。** 程序只读取剪贴板，不会自动获取 Keil 中的选中内容；顺序反了，翻译的会是上一次复制的内容。

## 🚀 首次运行 (Quick Start)

**环境要求**

- Windows 10 / 11（目前仅在 Windows 上验证）
- Python 3.10 及以上（本项目在 3.14 下运行通过），安装时建议勾选 `Add python.exe to PATH`
- 可访问 `api.deepseek.com` 的网络
- 一个可用的 DeepSeek API Key（账户需有余额）

**1. 获取代码**

将本仓库克隆或下载到本地，然后进入项目根目录（下文的命令都在项目根目录执行）：

```powershell
cd STM32Helper_V2
```

**2. 安装依赖**

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**3. 配置 API Key**

打开 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建 API Key，然后把 `.env.example` 复制为 `.env`：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，填入你的 Key：

```env
DEEPSEEK_API_KEY=sk-你的Key
```

> `.env` 已被 `.gitignore` 忽略。模板里的 `sk-xxxx...` 是占位符，保留它会被视为“未配置”。

**4. 启动**

推荐直接双击 `run.bat`：它会用 `.venv` 里的 `pythonw.exe` 在后台静默启动，不保留控制台。

如果想看到启动提示和报错信息，改用带控制台的方式启动：

```powershell
.\.venv\Scripts\python.exe .\main.py
```

看到下面的输出，说明快捷键注册成功：

```text
已启动：ALT+Q 翻译 | ALT+C 隐藏 | ALT+G 退出
```

**5. 开始使用**

1. 在 Keil 中选中函数、宏或注释；
2. 按 `Ctrl+C` 复制；
3. 按 `Alt+Q`；
4. 阅读悬浮窗中的解释；
5. 点击窗口 / `Esc` / `Alt+C` 收起；需要彻底退出时按 `Alt+G`。

## 🧭 工作原理 (How it works)

```text
选中代码 → Ctrl+C → Alt+Q
        → keyboard 全局热键 → pyperclip 读取剪贴板
        → openai SDK 请求 DeepSeek（deepseek-chat）
        → tkinter 无边框悬浮窗展示
```

API 请求放在后台线程执行，主界面每 80ms 轮询一次结果，因此翻译过程中窗口不会卡死；隐藏窗口后，尚未返回的结果会被丢弃，不会再把窗口弹出来。

## ⚙️ 配置与参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 模型 | `deepseek-chat` | 在 `main.py` 顶部的 `MODEL` 修改 |
| API 地址 | `https://api.deepseek.com` | OpenAI 兼容接口 |
| 单次输入上限 | 12,000 字符 | 超出部分自动截断 |
| 最大输出 | 512 tokens | 提示词要求约 150 字 |
| 请求超时 | 40 秒 | 超时后可在窗口提示下按 `Alt+Q` 重试 |
| 防抖间隔 | 0.7 秒 | 连按只触发一次 |
| 窗口宽度 | 620 px | 高度按内容自适应，最高 480 px |
| 温度 | 0.2 | 让输出更稳定 |

快捷键、模型、超时等参数都集中在 `main.py` 顶部，修改后重启程序生效。如需更换按键，编辑 `HOTKEY_SHOW`（默认 `alt+q`）、`HOTKEY_HIDE`（`alt+c`）、`HOTKEY_QUIT`（`alt+g`）即可。

API Key 的读取顺序为：项目根目录 `.env` → 系统环境变量 `DEEPSEEK_API_KEY`；两者都没有有效值时，悬浮窗会提示去配置。

## ❓ 常见问题 (FAQ)

| 现象 | 原因与处理 |
| --- | --- |
| 按 `Alt+Q` 没反应 | 快捷键注册失败或被安全软件拦截：查看悬浮窗/控制台是否有“快捷键注册失败”，尝试以管理员身份运行，或改掉 `main.py` 里的热键 |
| Keil 以管理员身份运行时不响应 | Windows 会限制低权限程序接收高权限窗口的按键，可能完全没有反应；把本工具也以管理员身份启动 |
| 和其它软件的快捷键冲突 | `Alt+Q` 是全局热键且不会拦截原按键，可能同时触发别的程序；换一个组合即可 |
| 点了窗口后程序直接退出 | 快捷键注册失败时，窗口没有再次唤出的入口，点击或按 `Esc` 会直接结束进程；先解决注册失败问题 |
| 提示“剪贴板为空” | 先复制一段代码文本再按 `Alt+Q`，确保剪贴板非空 |
| 提示“未配置 API Key” | `.env` 不存在、留空，或仍是 `sk-xxxx` 占位符；填好后重启程序 |
| 提示 401 / Key 无效 | Key 填错或已被吊销；到 DeepSeek 控制台重新生成，更新 `.env` 后重启 |
| 提示超时 / 无法连接 | 网络或代理问题；确认能访问 `api.deepseek.com`，必要时配置系统代理或 `HTTPS_PROXY` 环境变量 |
| 提示 402 / 429 / 额度不足 | 账户余额不足或请求过于频繁；到 DeepSeek 控制台充值/查看用量，稍后重试 |
| 解释显示不全 | 悬浮窗最高 480px；复制更短的片段，或调大 `main.py` 里的 `WINDOW_MAX_HEIGHT` |
| 改了 `.env` 不生效 | 配置只在启动时读取；修改后需要重启进程 |
| 双击 `run.bat` 提示找不到虚拟环境 | 还没创建 `.venv`；按“首次运行”的第 2 步安装依赖 |
| 双击 `run.bat` 后毫无反应 | `pythonw.exe` 没有控制台，依赖导入失败也不会提示；改用 `.\.venv\Scripts\python.exe .\main.py` 启动查看报错 |
| 无法彻底退出 | 先按 `Alt+G`；用控制台启动时也可按 `Ctrl+C`；若无响应，在任务管理器结束 `pythonw.exe` / `python.exe` |

## 🔒 隐私与安全

- **会上传什么**：按 `Alt+Q` 时，剪贴板中的文本会作为对话内容发送到 DeepSeek API（HTTPS），除此之外没有其它上传。
- **Key 存在哪**：只从项目根目录的 `.env` 或系统环境变量 `DEEPSEEK_API_KEY` 读取；不会写入日志，默认被 `.gitignore` 忽略。
- **敏感代码**：如果所在项目禁止把源码发送到第三方 API，请勿使用本工具，或把接口替换为本地模型。
- **Key 泄漏处理**：`.env` 一旦误提交，立即到 DeepSeek 控制台吊销并重新生成；提交前可用 `git status --short` 自查。

## ⚠️ 已知限制

- 仅面向 Windows；依赖全局键盘钩子，个别安全软件可能拦截。
- 没有缓存和历史记录，同一段代码重复查询会重复调用 API（按 token 计费）。
- 回答一次性返回（非流式），网络较慢时会先显示“正在翻译剪贴板中的代码…”。
- 提示词要求 150 字以内，模型偶尔会略超；悬浮窗超过 480px 的内容会被裁切，没有滚动条。
- 全局热键不会屏蔽原按键，可能与 Keil 或其它软件的同名快捷键同时触发。
